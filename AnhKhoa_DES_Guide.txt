================================================================================
1. 📋 TỔNG QUAN QUY TRÌNH
================================================================================

DES là thuật toán mã hóa khối 64-bit với key 56-bit.

QUY TRÌNH TỔNG QUÁT gồm 2 phần:

== Phần 1: Chạy vòng lặp với hàm f mỗi vòng chạy với một khóa ==
Plaintext (64-bit) 
    ↓
Initial Permutation (IP) 
    ↓
Split thành L0/R0 (32-bit mỗi phần)
    ↓
Chạy 16 Feistel Rounds với 16 Round Keys
    ↓
Combine R16 + L16 (chú ý hoán đổi!)
    ↓
Final Permutation (FP)
    ↓
Ciphertext (64-bit)

== Phần 2: Sinh khóa (Diễn ra độc lập với Phần 1) ==
Master Key (64-bit) → Key Schedule → 16 Round Keys (48-bit each)

================================================================================
5. 🔄 16 VÒNG FEISTEL ROUNDS
================================================================================

QUY TẮC FEISTEL (Làm đại diện chạy vòng lặp):
L(i+1) = R(i) => Đầu ra của thằng R làm đầu vào của thằng L
R(i+1) = L(i) ⊕ F(R(i), K(i))

FLOW CHI TIẾT: (Hàm F là gì => chi tiết ở bước 6)

ROUND 1:
Input:  L0, R0, K1
Process: L1 = R0
         R1 = L0 ⊕ F(R0, K1)
Output: L1, R1

ROUND 2:
Input:  L1, R1, K2  
Process: L2 = R1
         R2 = L1 ⊕ F(R1, K2)
Output: L2, R2

...tiếp tục đến...

ROUND 16:
Input:  L15, R15, K16
Process: L16 = R15
         R16 = L15 ⊕ F(R15, K16)
Output: L16, R16

SAU 16 ROUNDS:
Hợp lại thành 64bit = R16 + L16  (chú ý: R16 trước, L16 sau!)

Cách thực hiện: Đánh số từ 1 - 32 của R_32bit, sau dó điền theo thứ tự của E_table là được Expanded_R
R_32bit    = 11110000101010101100110000001111

BƯỚC 6.2: XOR VỚI CÁI KEY ĐƯỢC TRUYỀN VÀO
Expanded_R = 011110100000101010101011001100110000000011111
Round_Key  = 000110110000001011101111111111000111000001110010
XOR_Result = 011000010000100001000100110011110111000010001101 (Giống nhau = 0, Khác = 1)

BƯỚC 6.3: S-BOXES - từ 48-bit của thành 32-bit của  XOR_Result tương ứng

🔹 NGUYÊN LÝ S-BOXES:
Mỗi S-Box: 6-bit input → 4-bit output
Có 8 S-Boxes tương ứng với 8 nhóm 6-bit

🔹 CÁCH TÍNH ROW VÀ COLUMN:
6-bit input = b1 b2 b3 b4 b5 b6
- row = b1b6 (bit đầu + bit cuối) → 2 bit → 4 rows (0-3)
- col = b2b3b4b5 (4 bit giữa) → 4 bit → 16 columns (0-15)

🔹 THỰC HIỆN:
Chia XOR_Result thành 8 nhóm 6-bit:
Group 1: 011000
Group 2: 010000  
Group 3: 100001
Group 4: 000100
Group 5: 110011
Group 6: 110111
Group 7: 000010
Group 8: 001101

🔹 CHẠY CHI TIẾT:

GROUP 1: 011000
- row = 00 (bit đầu=0, bit cuối=0) = 0 (decimal)
- col = 1100 (4 bit giữa) = 12 (decimal)
- S1[0][12] = 5 = 0101 (4-bit output)

GROUP 2: 010000
- row = 00 (binary) = 0 (decimal)  
- col = 1000 (binary) = 8 (decimal)
- S2[0][8] = 9 = 1001 (4-bit output)

GROUP 3: 100001
- row = 11 (binary) = 3 (decimal)
- col = 0000 (binary) = 0 (decimal)
- S3[3][0] = 1 = 0001 (4-bit output)

GROUP 4: 000100
- row = 00 (binary) = 0 (decimal)
- col = 0010 (binary) = 2 (decimal)
- S4[0][2] = 13 = 1101 (4-bit output)

GROUP 5: 110011
- row = 11 (binary) = 3 (decimal)
- col = 1001 (binary) = 9 (decimal)
- S5[3][9] = 11 = 1011 (4-bit output)

GROUP 6: 110111
- row = 11 (binary) = 3 (decimal)
- col = 1011 (binary) = 11 (decimal)
- S6[3][11] = 14 = 1110 (4-bit output)

GROUP 7: 000010
- row = 00 (binary) = 0 (decimal)
- col = 0001 (binary) = 1 (decimal)
- S7[0][1] = 4 = 0100 (4-bit output)

GROUP 8: 001101
- row = 01 (binary) = 1 (decimal)
- col = 0110 (binary) = 6 (decimal)
- S8[1][6] = 13 = 1101 (4-bit output)

🔹 KẾT QUẢ SAU S-BOXES:
Kết hợp 8 nhóm 4-bit: 0101 1001 0001 1101 1011 1110 0100 1101
S-Box_Output = 01011001000111011011111001001101 (32-bit)

BƯỚC 6.4: P-BOX (PERMUTATION) - 32-bit → 32-bit

🔹 MỤC ĐÍCH:
- Hoán vị kết quả từ S-Boxes để tạo sự phân tán (diffusion)
- Đảm bảo mỗi bit output phụ thuộc vào nhiều bit input khác nhau
- Tăng độ phức tạp và bảo mật của thuật toán

🔹 CÁCH THỰC HIỆN:
P_table = [16,7,20,21,29,12,28,17, 1,15,23,26,5,18,31,10,
           2,8,24,14,32,27,3,9, 19,13,30,6,22,11,4,25]

Áp dụng: Permutation_Output[i] = S-Box_Output[P_table[i] - 1]

🔹 VÍ DỤ THỰC TẾ:
Input từ S-Boxes: 01011001000111011011111001001101
Đánh số vị trí:   12345678901234567890123456789012
                  1         2         3

🔹 CHI TIẾT CÁCH ĐỌC VỊ TRÍ:
Input chia thành nhóm: 01011001 | 00011101 | 10111110 | 01001101
Vị trí 1-8:           01011001
Vị trí 9-16:          00011101  
Vị trí 17-24:         10111110
Vị trí 25-32:         01001101

Áp dụng P_table:
- P_table[0] = 16 → lấy bit thứ 16 = 1 (vị trí 16 trong "00011101")
- P_table[1] = 7  → lấy bit thứ 7  = 1 (vị trí 7 trong "01011001")  
- P_table[2] = 20 → lấy bit thứ 20 = 1 (vị trí 20 trong "10111110")
- P_table[3] = 21 → lấy bit thứ 21 = 0 (vị trí 21 trong "10111110")
- P_table[4] = 29 → lấy bit thứ 29 = 1 (vị trí 29 trong "01001101")
- ... (tiếp tục cho 32 vị trí)

🔹 KẾT QUẢ CUỐI CÙNG:
F_Function_Output = 10010110011100001011010111000110 (32-bit)

🔹 TÓM TẮT LẠI HÀM F:
R_32bit →  E-box  → XOR vs K1 → S-Boxes → P-Permutation → F_Output
32-bit  → 48-bit  →  48-bit   →  32-bit →    32-bit     →  32-bit

7. 🔄 FINAL PERMUTATION (FP) - BƯỚC CUỐI CÙNG
================================================================================

🔹 VỊ TRÍ TRONG QUY TRÌNH DES:
Plaintext → IP → 16 Feistel Rounds → Combine R16+L16 → **FP** → Ciphertext

🔹 MỤC ĐÍCH:
- Nghịch đảo của Initial Permutation (IP)
- Hoàn thành quá trình mã hóa
- Đưa dữ liệu về dạng chuẩn cuối cùng

🔹 THỜI ĐIỂM THỰC HIỆN:
SAU 16 ROUNDS: R16 + L16 (64-bit) → Áp dụng FP

🔹 QUAN HỆ VỚI IP:
- IP(FP(x)) = x (nghịch đảo hoàn hảo)
- FP hoàn tác những gì IP đã làm

🔹 BẢNG FP (nghịch đảo của IP):
FP_table = [40,8,48,16,56,24,64,32, 39,7,47,15,55,23,63,31,
            38,6,46,14,54,22,62,30, 37,5,45,13,53,21,61,29,
            36,4,44,12,52,20,60,28, 35,3,43,11,51,19,59,27,
            34,2,42,10,50,18,58,26, 33,1,41,9,49,17,57,25]

🔹 CÁCH ÁP DỤNG:
Ciphertext[i] = Combined_64bit[FP_table[i] - 1]

🔹 VÍ DỤ:
Before_FP = R16 + L16 = 1010110011110000... (64-bit)
After_FP  = Final ciphertext = A1B2C3D4E5F60789 (hex)

🔹 SO SÁNH VỚI P-BOX:
- **P-Box**: Trong Hàm F, 32-bit, 16 lần, tạo diffusion
- **FP**: Cuối thuật toán, 64-bit, 1 lần, nghịch đảo IP

def string_to_bits(text):
    """Chuyển string thành binary"""
    return ''.join(format(ord(char), '08b') for char in text)

def permute(bits, table):
    """Áp dụng permutation table"""
    return ''.join(bits[i-1] for i in table)

def left_shift(bits, shifts):
    """Dịch trái vòng tròn"""
    return bits[shifts:] + bits[:shifts]

def xor(bits1, bits2):
    """XOR hai chuỗi bit"""
    return ''.join('0' if a == b else '1' for a, b in zip(bits1, bits2))

def des_demo():
    """Demo DES hoàn chỉnh với HELLO123 và MYSECRET"""
    
    print("=" * 50)
    print("        DES EDUCATIONAL DEMO")
    print("=" * 50)
    print()
    
    # Input
    plaintext = "HELLO123"
    key = "MYSECRET"
    print(f"📝 INPUT:")
    print(f"Plaintext: '{plaintext}'")
    print(f"Key:       '{key}'")
    print()
    
    # Chuyển đổi sang binary
    plaintext_bits = string_to_bits(plaintext)
    key_bits = string_to_bits(key)
    print(f"🔢 BINARY CONVERSION:")
    print(f"Plaintext: {plaintext_bits}")
    print(f"Key:       {key_bits}")
    print(f"Lengths:   {len(plaintext_bits)} bits each")
    print()
    
    # Initial Permutation
    ip_result = permute(plaintext_bits, IP)
    L0 = ip_result[:32]
    R0 = ip_result[32:]
    print(f"🔄 INITIAL PERMUTATION:")
    print(f"After IP: {ip_result}")
    print(f"L0:       {L0}")
    print(f"R0:       {R0}")
    print()
    
    # Key Schedule (PC-1)
    pc1_result = permute(key_bits, PC1)
    C0 = pc1_result[:28]
    D0 = pc1_result[28:]
    print(f"🔑 KEY SCHEDULE:")
    print(f"PC-1:     {pc1_result} (56-bit)")
    print(f"C0:       {C0} (28-bit)")
    print(f"D0:       {D0} (28-bit)")
    print()
    
    # Round Key Generation
    C1 = left_shift(C0, 1)
    D1 = left_shift(D0, 1)
    CD1 = C1 + D1
    K1 = permute(CD1, PC2)
    print(f"🔗 ROUND KEY 1:")
    print(f"C1:       {C1}")
    print(f"D1:       {D1}")
    print(f"CD1:      {CD1}")
    print(f"K1:       {K1} (48-bit)")
    print()
    
    # F Function Demo
    print(f"⚙️ F FUNCTION (Round 1):")
    
    # E-box expansion
    expanded_R0 = permute(R0, E)
    print(f"R0:           {R0}")
    print(f"Expanded R0:  {expanded_R0}")
    
    # XOR with round key
    xor_result = xor(expanded_R0, K1)
    print(f"K1:           {K1}")
    print(f"XOR result:   {xor_result}")
    print()
    
    # S-Box demo (full 8 S-Boxes)
    sboxes = [S1, S2, S3, S4, S5, S6, S7, S8]
    sbox_outputs = []
    print(f"📦 S-BOX DEMO (All 8 groups):")
    for i in range(8):
        group = xor_result[i*6:(i+1)*6]
        row = int(group[0] + group[5], 2)
        col = int(group[1:5], 2)
        sbox_val = sboxes[i][row][col]
        sbox_bin = format(sbox_val, '04b')
        sbox_outputs.append(sbox_bin)
        print(f"Group {i+1}: {group} → S{i+1}[{row}][{col}] = {sbox_val:2d} → {sbox_bin}")
    sbox_output_str = ''.join(sbox_outputs)
    print(f"S-Boxes Output (32-bit): {sbox_output_str}")
    
    # P-Box permutation
    pbox_output = permute(sbox_output_str, P)
    print(f"P-Box Output (32-bit):   {pbox_output}")
    print()
    
    # Complete Feistel Round
    print(f"🔄 FEISTEL ROUND STRUCTURE:")
    print(f"L(i+1) = R(i)")
    print(f"R(i+1) = L(i) ⊕ F(R(i), K(i))")
    print()
    print(f"For Round 1:")
    print(f"L1 = R0 = {R0}")
    print(f"R1 = L0 ⊕ F(R0,K1)")
    print(f"   = {L0}")
    print(f"   ⊕ {pbox_output}")
    r1 = xor(L0, pbox_output)
    print(f"   = {r1}")
    print()
    
    print("✅ DEMO COMPLETE!")
    print("📖 This demonstrates key DES operations:")
    print("   • Binary conversion")
    print("   • Initial Permutation (IP)")
    print("   • Key Schedule (PC-1, shifts, PC-2)")
    print("   • F Function (E-box, S-boxes, P-box)")
    print("   • Feistel Round structure")
    print()
    print("🔒 Note: DES is for educational use only!")
